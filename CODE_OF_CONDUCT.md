# Code of Conduct

LoopSite Studio welcomes constructive contributions from people of all backgrounds and experience levels.

## Our standards

Everyone participating in the project is expected to:

- Communicate respectfully and professionally, including when discussing mistakes or disagreements.
- Give technical feedback about code and behavior rather than attacking contributors.
- Respect different levels of experience, perspectives, and languages.
- Protect other people's privacy and avoid sharing private information without permission.
- Report harmful behavior and security problems through appropriate channels.

The following are not acceptable:

- Harassment, discrimination, threats, or targeted personal attacks.
- Sexualized harassment or unwelcome sexual attention.
- Trolling, insults, repeated disruptive behavior, or deliberate intimidation.
- Publishing private information without consent.
- Knowingly submitting malicious code or misleading security claims.

## Scope

These rules apply to repository issues, pull requests, reviews, discussions, and other spaces where someone represents or participates in the LoopSite Studio project.

## Reporting and enforcement

For conduct concerns, contact the repository maintainer **privately**, using an available private GitHub contact channel. Do not publish personal or sensitive details in public issues. If an incident takes place on GitHub and no private contact option is available, use GitHub's platform reporting tools.

The maintainer will review reports as circumstances allow, consider the impact and evidence, and may issue a warning, remove content, restrict participation, or ban accounts from project spaces. Reports will be handled as confidentially as practical. No specific response-time guarantee is made.

For software vulnerabilities, use the process in [SECURITY.md](SECURITY.md) instead.
