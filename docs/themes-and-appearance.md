# Workspace appearance

Settings → Appearance controls three independent local preferences.

- **Color mode** — System follows the operating system live. Studio Light and Studio Dark fix the palette for the app and editor. Existing colored themes migrate to the corresponding brightness.
- **Workspace layout** — Side navigation places projects in a list beside their details on desktop. Open in editor takes the selected project directly into the file explorer. Top navigation moves the tools to a header and projects into a horizontal selector above the details.
- **UI size** — Compact, Normal and Large scale text, navigation, and the workspace together.

Run `python scripts/verify-themes.py` to check palette completeness and text contrast.
